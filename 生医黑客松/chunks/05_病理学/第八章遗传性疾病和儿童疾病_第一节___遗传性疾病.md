# 第一节  |  遗传性疾病

人类的遗传信息是通过生殖细胞从亲代向子代传递的。遗传信息贮存在核基因组和线粒体基因
组中。目前，已知的核基因组DNA 序列有2.85×10 9 个碱基对，由基因、基因相关序列及基因外序列
构成。基因和基因相关序列包含编码序列（外显子）、间隔序列（内含子）和调控序列。基因外序列主
要由重复的核苷酸片段组成。线粒体基因组含两条环状的DNA 链，长16 569bp，共有37 个基因。当
DNA 链出现基因突变或表达程序错误时，就可能导致人体某些组织器官发育异常、发生疾病或肿瘤。
遗传性疾病在亲代和子代之间呈垂直传递并按一定比例出现，具有家族聚集的特点，而且绝大多
数遗传性疾病表现为先天性和终身性。但是，一些遗传性疾病并无家族史而是散发的，如常染色体隐
性遗传病和染色体病；还有一些遗传性疾病也不是先天性的，如亨廷顿舞蹈症患者在30～40 岁才发
病。先天性疾病或家族性疾病并非都是遗传性疾病。例如母亲妊娠早期感染风疹病毒，可导致婴儿
患先天性心脏病或先天性白内障。饮食中缺乏维生素A 可使一个家庭多个成员患夜盲症。
基因异常导致的儿童遗传性疾病较成人多见，因此本章将遗传性疾病和儿童疾病一起讨论。

### 一、  与遗传性疾病相关的基因异常

基因异常影响蛋白质的结构和功能，可导致遗传性疾病。当临床怀疑患者可能患遗传性疾病时，
可通过DNA、RNA 测序或染色体检查等发现异常的基因。
（一）  蛋白质编码基因突变
基因突变是DNA 的永久性改变。生殖细胞的基因突变（胚系突变）通过生殖导致子代的遗传性
疾病。体细胞的基因突变（体系突变）不通过生殖传递给子代，但能导致肿瘤和某些先天畸形。基因
突变的形式和效应如下。
1.  点突变（point mutation）  是指DNA 链中一个碱基（碱基对）被另一个碱基（碱基对）替换。点突
变导致编码的蛋白质中一种氨基酸被另一种氨基酸取代，这种突变称错义突变（missense mutation）。例
如，镰状细胞贫血就是由于HBB 基因的点突变导致血红蛋白β 珠蛋白链中正常的谷氨酸变成了缬氨
酸，形成血红蛋白S（HbS）。若碱基替换使原来编码某一氨基酸的密码子变成终止密码子，蛋白质翻
译终止而导致合成减少或不合成，称为无义突变（nonsense mutation）。
2.  移码突变（frame-shift mutation）  是指在DNA 编码序列中插入或缺失碱基，造成下游一系列
基因发生移位错误，其编码的氨基酸种类和顺序发生改变，影响蛋白质的生物学功能。例如囊性纤维
化（cystic fibrosis）常出现囊性纤维化跨膜转导调节因子（CFTR）基因突变，导致CFTR 蛋白异常或缺
失，患者出现多系统外分泌腺功能异常。
3.  编码基因拷贝数扩增（amplification）、缺失（deletion）和易位（translocation）  这些改变可导致
蛋白质的功能异常地增强或丧失。在多数情况下，生殖细胞的基因结构改变累及相邻的染色体而非
单个基因，如22q 缺失综合征。一些恶性肿瘤细胞常出现基因扩增、缺失或易位。
4.  三核苷酸重复序列突变（trinucleotide repeat mutation）  是指基因组中脱氧三核苷酸串联重
