> **Track**: 02 - 学科知识整合智能体
> **Vision**: 构建一个具备深度理解、去重提纯、可视化交互与教学迭代能力的医学知识大脑。

---

## 1. 五大核心命题 (Core Tasks)

1. **多源加载 (Multi-Source)**: 
   - 自动加载并解析多本教材与辅助书籍（支持 PDF, MD, Word, Excel）。
2. **单本构建 (Single Map)**: 
   - 为每一本教材独立构建高精度的知识图谱。
3. **跨教材整合 (Cross-Textbook)**: 
   - 识别知识点在不同教材间的**重叠、互补与缺失**。
4. **精华提纯 (30% Essence)**: 
   - 将多本教材内容压缩至原始体量的 **30% 以内**，保留核心精华。
5. **教学反馈 (Teacher Loop)**: 
   - 支持与学科教师多轮对话，动态优化整合方案。

## 2. 六大基本功能要求 (Functional Requirements)

- [ ] **F1: 多格式支持**: 兼容 PDF, Markdown, Word, Excel 等。
- [ ] **F2: 标准化图谱**: 关系类型必须包含：**前置依赖、并列关系、包含关系、应用关系**。
- [ ] **F3: 交互式可视化**: 图谱需支持用户缩放、点击、关联探索。
- [ ] **F4: 质量受控整合**: 确保合并过程中的医学逻辑准确性。
- [ ] **F5: 决策透明化**: 对每一项整合/去重决策给出明确的理由。
- [ ] **F6: 全套交付物**: 包括 Web 交互界面、整合报告、开发文档。

## 3. 关键挑战与应对 (Key Challenges)

| 挑战项 | 应对策略 |
| :--- | :--- |
| **知识粒度定义** | 以“节 (Section)”为语义块，以“三元组 (Triplet)”为逻辑原子。 |
| **重复判定标准** | 结合 Embedding 语义相似度与三元组结构对齐。 |
| **教学连贯性** | 以《临床医学专业教学大纲》作为全局拓扑骨架。 |
| **30% 压缩比控制** | 实施“去重、摘要、分级保留”三步法。 |
