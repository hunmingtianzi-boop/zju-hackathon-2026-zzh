# 知识整合智能体 (KIA) - 前端开发需求与执行清单

> **阶段**: Web 交互界面开发 (Group C)
> **目标**: 构建符合“数字化科研美学”的高性能、高清晰度交互图谱。

## 1. 核心功能全景图 (Feature Map)

### 1.1 可视化画布 (Graph Canvas)
- [ ] **高清晰度连线与指向**: 确保节点之间不拥挤，有足够的排斥力。连线必须有极其明确的方向箭头（解决“粘在一起、指向不明”的问题）。
- [ ] **四类关系精准映射**: 必须通过不同的颜色/线型严格区分“前置依赖、并列、包含、应用”这四种赛题要求的关系。
- [ ] **多布局支持**: 提供“力导向图 (展现网状关系)”与“层级树状图 (展现教学连贯大纲)”的切换。

### 1.2 数据审计侧边栏 (Audit & Reasoning Panel)
- [ ] **多源追踪**: 点击节点必须清晰展示该知识点提取自哪几本书。
- [ ] **决策透明化**: 展示 AI 合并/去重该节点的“逻辑理由”（满足赛题 F5 要求）。
- [ ] **提纯结果对比**: 展示原始长度与提纯后的 30% 精华文本。

### 1.3 交互与反馈闭环 (Interaction & Teacher Loop)
- [ ] **图谱漫游**: 支持平滑的缩放、拖拽，并提供“一键自适应全屏”功能。
- [ ] **实时过滤器**: 勾选框，可随时隐藏/显示特定的关系类型或特定教材的数据。
- [ ] **教师修正模式**: 在节点上提供操作入口，允许人工输入反馈意见，触发“重新整合”的模拟交互。

### 1.4 全局监控 (Global Metrics)
- [ ] **整合指标仪**: 实时动态显示当前图谱的“节点数”、“关系数”以及“总压缩率”。

- **Step 2**: 引入“层级 (Dagre/Breadthfirst)”布局，测试知识树的可读性。
