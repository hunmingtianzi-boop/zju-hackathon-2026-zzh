## 1. 项目概览 (Project Overview)
本项目旨在为 2026 年浙江大学生医黑客松提供一套高度结构化的、具备语义检索能力的医学知识底座。基于 2024 年第 10 版国家卫健委“十四五”规划教材，实现了从原始 PDF 到高精度语义切片的完整工程化转换。

## 2. 数据源 (Data Sources)
核心知识库涵盖 7 本权威临床医学教材（第 10 版）：
- `01_局部解剖学`
- `02_组织学与胚胎学`
- `03_生理学`
- `04_医学微生物学`
- `05_病理学`
- `06_传染病学`
- `07_病理生理学`

## 3. 技术管线 (Technical Pipeline)

### A. 结构化解析 (Structured Parsing)
- **脚本**: `process_all_textbooks.py`
- **逻辑**: 利用 `PyMuPDF` 解析字体元数据，通过字体大小与正则模式自动识别章节（H1-H3）及临床病例分析块。
- **优化**: 自动剔除页眉、页脚及扫描杂质，保留医学文本的层级逻辑。

### B. 语义切片 (Semantic Chunking)
- **脚本**: `chunk_textbooks.py`
- **结果**: 生成 **1295 个** 语义单元（Chunks）。
- **策略**: 按“节”物理拆分，确保每个单元包含完整的知识点及上下文标题。
- **存储**: 位于 `生医黑客松/chunks/` 目录下。

### C. 混合检索引擎 (Hybrid Search Engine)
- **脚本**: `search_engine.py`
- **双路召回**:
    1. **BM25 (Keyword)**: 针对医学专有名词的精确匹配。
    2. **Vector (Semantic)**: 基于 `text2vec-base-chinese` 模型的语义空间检索。
- **向量数据库**: `FAISS (IndexFlatL2)`。
- **索引文件**:
    - `medical_index_faiss.index`: 高维向量索引。
    - `medical_index_meta.pkl`: 元数据映射。

## 4. 调用指南 (Usage for AI Agents)

### 快速检索示例
```python
from search_engine import MedicalSearchEngine

# 初始化并加载索引
engine = MedicalSearchEngine()
engine.load('medical_index')

# 执行混合检索
query = "二尖瓣狭窄的临床表现"
results = engine.search(query, top_k=5)

# 结果包含：分值、原文路径、内容片段
for res in results:
    print(f"Path: {res['path']}, Score: {res['score']}")
```
