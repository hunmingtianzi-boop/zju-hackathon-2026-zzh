## 四、教学完整性分析

### 4.1 跨教材互补

系统发现了 **279 处互补关系**——某教材中存在但另一教材中缺失的知识关联。例如：

- 《局部解剖学》提供心脏的空间位置结构
- 《生理学》提供心功能的控制机理
- 《病理生理学》提供心功能不全的发生发展机制

三本教材在心功能主题上形成 **空间结构 → 正常功能 → 病理机制** 的完整知识链。

### 4.2 冗余消除

以下高频重复概念已识别并建议合并：

| 概念 | 出现教材数 | 处理 |
|---|---|---|
| 炎症 | 5 本 | 保留《病理学》版本（描述最系统完整） |
| 发热 | 3 本 | 保留《病理生理学》版本 |
| 肿瘤 | 4 本 | 保留《病理学》版本 |
| 感染 | 4 本 | 保留《医学微生物学》+《传染病学》互补版本 |

### 4.3 端到端案例：心功能不全的三元组级整合

以下展示"心功能不全"主题从原始三元组 → 合并决策 → 精华压缩的完整链路：

**原始三元组（跨 3 本教材采样）**：

| 教材 | Subject | Relation | Object |
|---|---|---|---|
| 生理学 | 心脏收缩功能 | prerequisite | 心输出量评估 |
| 生理学 | 心输出量 | application | 心功能评估 |
| 病理生理学 | 心功能不全 | containment | 心输出量减少 |
| 病理生理学 | 心功能不全 | containment | 机体代偿反应 |
| 病理生理学 | 心脏收缩功能 | parallel | 心脏舒张功能 |
| 局部解剖学 | 心脏解剖 | prerequisite | 心功能评估 |
| 局部解剖学 | 心室结构 | containment | 心脏解剖 |

**合并决策**：

| 决策 ID | 类型 | 涉及节点 | 置信度 | 理由 |
|---|---|---|---|---|
| decision_01842 | merge | 生理学::心输出量 + 病理生理学::心输出量减少 | 0.88 | FAISS 语义匹配，均为"心输出量"相关概念 |
| decision_01843 | complement | 局部解剖学::心脏解剖 → prerequisite → 生理学::心功能评估 | 0.92 | 解剖学提供结构基础，生理学提供功能评估，形成教学递进链 |
| decision_01844 | conflict | 病理生理学::心功能不全 → containment → 心功能不全（自环） | — | 已自动排除 |

**最终压缩输出**（Tier 1，摘自 `essence_strict.md`）：

> **心功能不全**：心脏泵血功能下降导致心输出量不能满足机体代谢需求的病理生理过程。涉及收缩功能与舒张功能的异常，机体通过神经体液代偿机制维持灌注。**结构基础**（《局部解剖学》）→ **功能机制**（《生理学》）→ **病理进程**（《病理生理学》）形成完整教学链。

### 4.4 已知局限

- **去重率偏低**（2.26%）：当前三元组为规则抽取，缺少语义深度。大量语义相同但标签不同的知识点未被合并。接入 LLM 抽取后可显著提升去重率。
- **孤立节点偏多**（33.5%）：部分是由于 PDF 碎片节点（编委名单、ISBN 等）未完全过滤。后续需强化噪声过滤。
- **Application 关系稀疏**（6.9%）：大量隐含的临床联系未被规则抽取器捕获，需 LLM 补充。
